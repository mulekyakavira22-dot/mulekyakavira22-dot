## À l'atelier

### Merry Google

Un espace web personnel qui associe une connexion avec Google à un profil professionnel personnalisable. Le projet comprend une page de connexion, une page d'accueil après connexion et des sections pour mettre en valeur sa présentation, ses compétences, son parcours, ses projets et ses coordonnées.

**Dans le projet :** HTML · CSS · JavaScript · Google Identity Services · mise en page adaptative

[Découvrir le dépôt Merry Google →](https://github.com/heritierjunior/merry-google)

## Ma façon de construire

- **Une expérience soignée :** une interface claire qui s'adapte aux mobiles et aux ordinateurs.
- **Un profil personnel :** les informations du profil peuvent être adaptées à chaque personne.
- **Des bases web compréhensibles :** HTML, CSS et JavaScript sans framework imposé.
- **Une connexion encadrée :** Google Identity Services pour la connexion côté navigateur.
